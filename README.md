# Авторская методика: от идеи до диплома · DF Институт Учителей

Как выложить на GitHub Pages:
1. github.com → New repository → имя, например `avtorskaya-metodika` → Public → Create.
2. «uploading an existing file» → перетащить ВСЁ содержимое этой папки (index.html, konstruktor.html, kimi-1.html, kimi-2.html, папки img, pdf, kimi-1, kimi-2) → Commit changes.
3. Settings → Pages → Branch: main, папка / (root) → Save.
4. Через 1–2 минуты сайт откроется по адресу https://ИМЯ.github.io/avtorskaya-metodika/
